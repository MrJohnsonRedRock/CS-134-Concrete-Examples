# CS-134 Concrete Examples: How to Follow Along

## Once, on the first day

1. Install **GitHub Desktop** and sign in.
2. **File > Clone repository > URL**, and paste
   `https://github.com/MrJohnsonRedRock/CS-134-Concrete-Examples`
3. Open the cloned folder in **Unity Hub** (Add > Add project from disk).

## Every class

1. In Unity, click **CIT134 > Get Latest Lesson**.
   *It sets aside any changes you made to the class project, then downloads today's lesson.*
2. Open **Assets/Scenes/Level1**.
3. In the Hierarchy, click **Lessons**.
4. In the Inspector, find today's session (for example **Session15**) and set **Step**
   to the number on the slide.
5. Press **Play** and read the HUD. **Predict first**, then look.

Change the Step and press Play again for the next slide. Press **H** to hide the HUD.

## When a step says "uncomment"

Some lessons show you a mistake. The step tells you which file to open and which
lines to uncomment. Do it, save, and read the Console. You don't need to undo it:
Get Latest Lesson sets it aside next class.

## Your own code

Put your experiments in **Assets/Playground**. That folder is yours, and Get Latest
Lesson never touches it. Read the README in there before you start.

## If Get Latest Lesson says it can't find git

Do the same thing in GitHub Desktop:

1. **Branch > Stash All Changes**
2. **Repository > Pull**
