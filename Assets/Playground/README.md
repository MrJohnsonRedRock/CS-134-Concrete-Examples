# Playground

This folder is yours. Anything you make here stays on your computer:
**CIT134 > Get Latest Lesson** never stashes it, and a pull never touches it.

Everything outside this folder belongs to the class project. Change whatever you
like out there, but expect Get Latest Lesson to set those changes aside.

Two habits that save you trouble:

- **Start your class names with `My`** (`MyEnemy`, `MyLootDrop`). A future
  lesson might add an `Enemy` or a `LootDrop`, and two classes with the same name
  stop the whole project from compiling.
- **If your Playground code won't compile, nothing runs**, the lessons included.
  Fix it or comment it out before you press Play on a lesson.
